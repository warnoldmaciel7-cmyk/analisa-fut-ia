# Analisa Fut IA

Projeto inicial para o repositório `analisa-fut-ia`, com uma estrutura moderna para desenvolvimento web em React + Vite.

## Visão geral

Este projeto serve como base para construir uma aplicação voltada à análise de dados, IA e experiências de usuário em um ambiente simples e escalável.

## Tecnologias

- React
- Vite
- JavaScript

## Estrutura do projeto

```bash
analisa-fut-ia/
├── public/
├── src/
│   ├── App.jsx
│   ├── main.jsx
│   └── styles.css
├── .gitignore
├── index.html
├── package.json
├── README.md
├── vite.config.js
└── yarn.lock (opcional)
```

## Pré-requisitos

- Node.js 18+
- npm ou yarn

## Como instalar

```bash
npm install
```

## Como executar

```bash
npm run dev
```

A aplicação ficará disponível em:

```bash
http://localhost:5173
```

## Como gerar build de produção

```bash
npm run build
```
